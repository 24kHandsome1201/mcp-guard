# examples

Example inputs currently come from `testdata/` so they are executable in tests and easy to reuse from the CLI.

Useful starting points:
- install example: `./testdata/install/safe.json`
- identity example set: `./testdata/identity/`
- auth example: `./testdata/auth/safe.json`
- diff example set: `./testdata/diff/`

As the repository grows, this directory should hold user-facing examples rather than test fixtures.
